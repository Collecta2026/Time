# Time — Installation guide (step by step)

The full illustrated manual is **docs/Time_Installation_and_User_Manual.docx**. This is the
quick reference.

## A. Run locally (to try it)

1. Install **Python 3.12**.
2. In the project folder: `pip install -r requirements.txt`
3. `python app.py`
4. Open `http://localhost:5000` and sign in with **admin@time.eg / Time2026** (demo data loads on
   first run).

## B. Deploy to production — GitHub → Render → Neon

**Step 1 — Database (Neon).** Create a Neon project in the **London** region. Copy its **pooled**
connection string (starts `postgresql://`).

**Step 2 — Code (GitHub).** Create a repository and upload the project. Use **GitHub Desktop** so
the `templates/` and `static/` folders stay intact.

**Step 3 — App (Render).** New → **Blueprint** → select the repo. `render.yaml` is detected. Set:

| Variable | Value |
|---|---|
| `DATABASE_URL` | Neon connection string from Step 1 |
| `ADMIN_EMAIL` | your administrator email |
| `ADMIN_PASSWORD` | a strong password |
| `SEED_DEMO` | `true` for the first deploy (demo data), else `false` |
| `SECRET_KEY` | auto-generated by Render |

**Step 4 — First boot.** Render builds and starts the app; tables are created automatically and the
admin account is made from your variables. Open the Render URL and sign in.

**Step 5 — Clean start & domain.** If you loaded demo data, set `SEED_DEMO=false` and redeploy for a
clean database. Add your web address under **Settings → Custom Domains**.

## C. Load your data (in this order)

1. **Settings** — company, paying bank, statutory rates, leave policy, scheme-of-delegation bands.
2. **Users** — HR, Finance Manager, Managing Director accounts with roles.
3. **Departments**, then **Grades & spine points**.
4. **Employees**.
5. **Attendance** — import the first month.

## D. Going-live checklist

- [ ] Admin password changed from default
- [ ] Statutory rates confirmed for the current year
- [ ] Paying-bank details entered
- [ ] Delegation bands set to your limits
- [ ] Real users created; demo logins removed
- [ ] `SEED_DEMO=false`

## E. Yearly maintenance

Each January raise the insurable-wage **floor and ceiling by 15%** in Settings. Update any other
rates in Settings when the law changes — no code change needed.
